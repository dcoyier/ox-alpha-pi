# ox-alpha-pi

This repository is an OpenCode workspace. The default model is **Ox Alpha Free** (`opencode/x-preview-f-free`) via OpenCode Zen, with thinking level **max**. Available levels: `low`, `high`, `max`.

## Layout

- `opencode.json` — project OpenCode config, including the default model
- `AGENTS.md` — project instructions for the coding agent
- `README.md` — install and run notes

## Working here

- Prefer small, focused changes with clear commit messages.
- Do not commit API keys, tokens, or local auth files.
- Keep OpenCode config in `opencode.json` rather than personal global config when the setting should apply to this repo.
